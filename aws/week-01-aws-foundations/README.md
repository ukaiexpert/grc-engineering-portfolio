# Week 1 – AWS Foundations

## What I Learned

This week I started learning the fundamentals of Amazon Web Services (AWS).

Topics covered:

- What AWS is and how cloud computing works
- AWS Global Infrastructure
- AWS Regions
- Availability Zones
- Ways of interacting with AWS

## Why This Matters for GRC

Understanding AWS architecture is important for GRC because security and compliance controls need to be implemented within the underlying cloud environment.

For example, AWS Regions can affect data residency requirements, while Availability Zones are relevant to resilience and availability.

AWS also provides APIs and other interfaces that can potentially be used to collect security configuration and compliance evidence automatically.

## GRC Engineering Perspective

Traditional GRC processes often rely on manually collected evidence such as screenshots, documents and questionnaires.

As I progress through this portfolio, I want to explore how AWS configuration can be queried and evaluated programmatically to provide repeatable evidence of control operation.
